# AppShield

![AppShield logo](./assets/logo.svg)

AppShield is an Android application that uses Android's VPN service
to block network traffic for selected installed applications.

## Features

- View installed applications.
- Search installed applications.
- Select individual applications.
- Select all displayed applications.
- Block selected applications' network traffic.
- Start and stop VPN protection.

## Requirements

- Android 6.0 or later.
- VPN permission granted by the user.

## How it works

AppShield routes selected applications through a local VPN interface.
Their network packets are discarded rather than forwarded.
